# E-Commerce Sales Analysis Project

## Overview
This project explores an e-commerce sales dataset to understand business performance, product sales, profitability, and customer purchasing patterns. The analysis was carried out using Python, SQL, and Power BI to organize data, identify trends, and present findings through interactive visualizations.

## Project Objectives
- Understand overall sales and profit performance.
- Analyze product and category-wise sales.
- Identify products generating higher revenue.
- Explore customer purchasing behavior.
- Examine sales across cities, states, and channels.
- Analyze order patterns and payment preferences.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- Power BI
- DAX
- Excel

## Project Process

### 1. Data Preparation & Analysis – Python
Used Python and Pandas to inspect and prepare the dataset for analysis.

- Checked dataset structure and data types.
- Handled missing values and duplicate records.
- Performed data cleaning and preprocessing.
- Conducted exploratory data analysis (EDA).
- Analyzed sales, products, and customer trends.
- Created visualizations using Matplotlib and Seaborn.

**File:** `E-COMMERCE_PROJECT.ipynb`

### 2. Business Analysis – SQL
Used SQL queries to analyze transactional data and answer business-related questions.

- Sales and revenue analysis
- Product performance analysis
- Profitability analysis
- Category-wise comparisons
- Customer and order analysis
- Payment method analysis

**File:** `Ecommerce_SQL_Analysis.sql`

### 3. Interactive Dashboard – Power BI
Developed a three-page interactive report to present the analysis in a clear and structured manner.

**Page 1 – Executive Business Overview**
- Overall sales, profit, orders, and customers
- Sales by product category and channel
- State-wise sales performance
- Payment method analysis
- Monthly sales trend

**Page 2 – Product & Profit Analysis**
- Product category profitability
- Quantity sold by category
- Top-performing products
- Sales vs. profit comparison
- City-wise sales distribution

**Page 3 – Customer & Order Insights**
- Customer rating analysis
- Product quantity analysis
- Customer purchase segmentation
- Sales and profit by customer
- Payment method performance
